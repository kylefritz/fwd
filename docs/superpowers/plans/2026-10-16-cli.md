# fwd Command Line Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `fwd` command that people and coding agents on the Mac can use to forward ports, read status and wait for servers, by talking to the running fwd app over a private Unix socket.

**Architecture:** The app gains a `ControlServer` (a Unix socket in fwd's owner-checked socket folder) that hands each one-line JSON request to a `ControlHandler`, which runs it through the same `AppModel` actions the panel uses. A new Swift executable, `fwd-cli`, replaces the `scripts/fwd` shell script at `fwd.app/Contents/Resources/bin/fwd`: it parses arguments, starts the app if needed, sends the request and prints human or JSON output. Everything except the socket syscalls and process launching lives in `FwdCore` so it can be unit tested.

**Tech Stack:** Swift 6 toolchain in Swift 5 language mode, SwiftPM, Swift Testing, Darwin sockets, Foundation `Codable`.

**Spec:** `docs/superpowers/specs/2026-10-16-cli-design.md`

## Global Constraints

- Work on the `cli` branch; never push to `main` (every push to `main` publishes a beta).
- `fwd` with no arguments opens the window: `open -b io.github.kylefritz.fwd --args --show-window`, falling back to opening the enclosing bundle.
- `fwd --version` prints exactly the version string and nothing else (CI and Homebrew compare it with the tag); `dev` outside a bundle.
- Commands: `forward` (default), `status`, `wait`, `off`, `remove`, `keep`, `connect`, `screen`. Flags: `--json`, `--keep`, `--wait`, `--all`, `--off`, `--timeout S`.
- Default timeouts: `forward` 30s, `connect` 30s, `wait` 60s.
- Exit codes: 0 done, 1 couldn't do it, 2 bad usage, 3 app unreachable or protocol mismatch, 4 timed out.
- Socket: `<socketDir>/control.sock`, mode 0600, in the folder `SSHConnection.prepareSocketDir` checks; peer must be the same uid; one request line of at most 64 KB, read within 5 seconds; protocol version `v: 1`.
- `--json` prints exactly one JSON object on stdout, errors included.
- Every CLI request is logged as `cli: <cmd> <args>`.
- Follow the repo's style: comments explain why, sentence-case prose, no emoji in code.
- Run tests with `make test`; filter with `make test TEST_ARGS="--filter <Name>"`.

## Review Focus

- **A host whose name parses as a port** (e.g. an ssh `Host 8080`): it must be treated as the host, since it's known. Test in Task 3.
- **Quoted multi-word ports** (`"3000 -> 4000"`, `"5173 web"` as one argument): must be one port, with its name. Test in Task 3.
- **The card list lagging the session by a run-loop turn** right after a click: `forward`/`connect` must not report `standby` as a failure before the session has started. Test in Task 4.
- **A client that connects and sends nothing, or sends a huge line**: the server must time out or reject it without blocking other clients. Test in Task 5.
- **The app not running** when the command is used: the command starts it and retries, and exits 3 with a clear message if it never answers. Test in Task 7 (the retry loop, with a launcher stub).

```swift
import Foundation

/// What the `fwd` command sends the app: one line of JSON per connection.
public struct ControlRequest: Codable, Equatable, Sendable {
    /// Bumped when a request or reply changes shape, so a command and an app
    /// from different versions fail clearly instead of misreading each other.
    public static let version = 1

    public var v: Int
    public var cmd: String
    /// Positional arguments exactly as typed; the app resolves host and ports.
    public var args: [String]
    public var keep: Bool
    public var wait: Bool
    public var off: Bool
    public var all: Bool
    public var timeout: Double?

    public init(cmd: String, args: [String] = [], keep: Bool = false, wait: Bool = false,
                off: Bool = false, all: Bool = false, timeout: Double? = nil) {
        self.v = Self.version
        self.cmd = cmd
        self.args = args
        self.keep = keep
        self.wait = wait
        self.off = off
        self.all = all
        self.timeout = timeout
    }

    public static func decode(_ line: Data) throws -> ControlRequest {
        try JSONDecoder().decode(ControlRequest.self, from: line)
    }

    public func encodedLine() -> Data { ControlCoding.line(self) }
}

/// The command's exit status, also carried in failed replies.
public enum ExitCode: Int, Codable, Sendable {
    case ok = 0, failed = 1, usage = 2, unreachable = 3, timedOut = 4
}

public struct ControlError: Error, Equatable, Sendable {
    public let code: ExitCode
    public let message: String

    public init(_ code: ExitCode, _ message: String) {
        self.code = code
        self.message = message
    }

    public static func usage(_ message: String) -> ControlError { ControlError(.usage, message) }
    public static func failed(_ message: String) -> ControlError { ControlError(.failed, message) }
    public static func timedOut(_ message: String) -> ControlError { ControlError(.timedOut, message) }
    public static let versionMismatch = ControlError(
        .unreachable, "This fwd command and the fwd app are different versions; update fwd.")
}

/// One forwarded port of a range.
public struct ForwardInfo: Codable, Equatable, Sendable {
    public let remote: Int
    public let local: Int?
    public let url: String?
    public let state: String

    public func encode(to encoder: Encoder) throws {
        var c = encoder.container(keyedBy: CodingKeys.self)
        try c.encode(remote, forKey: .remote)
        try c.encode(local, forKey: .local)
        try c.encode(url, forKey: .url)
        try c.encode(state, forKey: .state)
    }
}

/// A port as the command line reports it. Every key is always present,
/// null when it has no value, so agents can rely on the shape.
public struct PortInfo: Codable, Equatable, Sendable {
    public let port: String
    public let name: String?
    public let on: Bool
    public let keep: Bool
    public let state: String
    public let reason: String?
    public let local: Int?
    public let url: String?
    public let forwards: [ForwardInfo]

    public init(port: String, name: String?, on: Bool, keep: Bool, state: String, reason: String?,
                local: Int?, url: String?, forwards: [ForwardInfo]) {
        self.port = port
        self.name = name
        self.on = on
        self.keep = keep
        self.state = state
        self.reason = reason
        self.local = local
        self.url = url
        self.forwards = forwards
    }

    public init(pill: Pill) {
        self.init(port: pill.text, name: pill.name, on: pill.on, keep: pill.keep,
                  state: Self.stateName(pill.state), reason: Self.reason(pill.state),
                  local: pill.local, url: pill.openURL?.absoluteString,
                  forwards: pill.ports.map {
                      ForwardInfo(remote: $0.remote, local: $0.local, url: $0.openURL?.absoluteString,
                                  state: Self.stateName($0.state))
                  })
    }

    public func encode(to encoder: Encoder) throws {
        var c = encoder.container(keyedBy: CodingKeys.self)
        try c.encode(port, forKey: .port)
        try c.encode(name, forKey: .name)
        try c.encode(on, forKey: .on)
        try c.encode(keep, forKey: .keep)
        try c.encode(state, forKey: .state)
        try c.encode(reason, forKey: .reason)
        try c.encode(local, forKey: .local)
        try c.encode(url, forKey: .url)
        try c.encode(forwards, forKey: .forwards)
    }

    static func stateName(_ state: PillState) -> String {
        switch state {
        case .off: return "off"
        case .pending: return "pending"
        case .waiting: return "waiting"
        case .live: return "live"
        case .active: return "active"
        case .blocked: return "blocked"
        case .invalid: return "invalid"
        }
    }

    static func reason(_ state: PillState) -> String? {
        switch state {
        case .blocked(let why), .invalid(let why): return why
        default: return nil
        }
    }

    /// Forwarded: a tunnel exists, whether or not a server answers yet.
    var isForwarded: Bool { ["waiting", "live", "active"].contains(state) }
    /// A server answers on the remote port (for a range, on at least one).
    var isLive: Bool {
        ["live", "active"].contains(state) || forwards.contains { ["live", "active"].contains($0.state) }
    }
}

public struct HostInfo: Codable, Equatable, Sendable {
    public let host: String
    public let state: String
    public let status: String
    public let inSSHConfig: Bool
    public let ports: [PortInfo]

    /// `only` limits the ports to those entries (by canonical text).
    public init(card: HostCard, only: Set<String>? = nil) {
        host = card.name
        state = Self.stateName(card.state)
        status = card.statusLine
        inSSHConfig = card.inConfig
        ports = card.pills.filter { only?.contains($0.text) ?? true }.map(PortInfo.init(pill:))
    }

    static func stateName(_ state: HostState) -> String {
        switch state {
        case .idle: return "idle"
        case .standby: return "standby"
        case .connecting: return "connecting"
        case .connected: return "connected"
        case .retrying: return "retrying"
        case .paused: return "paused"
        case .needsAttention: return "needs-attention"
        }
    }
}

public struct ControlReply: Codable, Equatable, Sendable {
    public let ok: Bool
    public let code: Int?
    public let error: String?
    public let host: HostInfo?
    public let hosts: [HostInfo]?
    public let url: String?

    public static func success(host: HostInfo) -> ControlReply {
        ControlReply(ok: true, code: nil, error: nil, host: host, hosts: nil, url: nil)
    }

    public static func success(hosts: [HostInfo]) -> ControlReply {
        ControlReply(ok: true, code: nil, error: nil, host: nil, hosts: hosts, url: nil)
    }

    public static func success(host: HostInfo, url: String) -> ControlReply {
        ControlReply(ok: true, code: nil, error: nil, host: host, hosts: nil, url: url)
    }

    public static func failure(_ error: ControlError, host: HostInfo? = nil) -> ControlReply {
        ControlReply(ok: false, code: error.code.rawValue, error: error.message, host: host, hosts: nil, url: nil)
    }

    public var exitCode: ExitCode { ok ? .ok : (code.flatMap(ExitCode.init(rawValue:)) ?? .failed) }

    public static func decode(_ line: Data) throws -> ControlReply {
        try JSONDecoder().decode(ControlReply.self, from: line)
    }

    public func encodedLine() -> Data { ControlCoding.line(self) }
}

enum ControlCoding {
    /// Sorted keys and no pretty printing: one line, the same bytes every time.
    static func line<T: Encodable>(_ value: T) -> Data {
        let encoder = JSONEncoder()
        encoder.outputFormatting = [.sortedKeys, .withoutEscapingSlashes]
        var data = (try? encoder.encode(value)) ?? Data("{}".utf8)
        data.append(UInt8(ascii: "\n"))
        return data
    }
}
```

```swift
// Sources/FwdCore/Control/CLIArguments.swift
import Foundation

/// What a `fwd` command line asks for.
public enum Invocation: Equatable {
    case openWindow
    case version
    case help
    case request(ControlRequest, json: Bool)
    /// Bad usage, with the message to print; exit 2.
    case usage(String)
}

/// Turns `fwd`'s arguments into an invocation. Hosts and ports aren't
/// checked here: only the app knows the hosts, so it resolves them.
public enum CLIArguments {
    public static let commands = ["forward", "status", "wait", "off", "remove", "keep", "connect", "screen"]

    public static func parse(_ args: [String]) -> Invocation {
        if args.isEmpty { return .openWindow }
        if args == ["--version"] || args == ["-v"] { return .version }
        if args.contains("--help") || args.contains("-h") { return .help }

        var json = false, keep = false, wait = false, off = false, all = false
        var timeout: Double?
        var words: [String] = []
        var i = 0
        while i < args.count {
            let arg = args[i]
            i += 1
            switch arg {
            case "--json": json = true
            case "--keep": keep = true
            case "--wait": wait = true
            case "--off": off = true
            case "--all": all = true
            case "--timeout":
                guard i < args.count else { return .usage("--timeout needs a number of seconds") }
                guard let seconds = Double(args[i]), seconds > 0 else { return .usage("--timeout needs a number of seconds, not \"\(args[i])\"") }
                timeout = seconds
                i += 1
            default:
                if arg.hasPrefix("--timeout=") {
                    guard let seconds = Double(arg.dropFirst("--timeout=".count)), seconds > 0 else {
                        return .usage("--timeout needs a number of seconds")
                    }
                    timeout = seconds
                } else if arg.hasPrefix("-"), arg.count > 1, Double(arg) == nil {
                    return .usage("unknown option \(arg) (try fwd --help)")
                } else {
                    words.append(arg)
                }
            }
        }
        guard let first = words.first else { return .usage("say what to do, like: fwd 3000 (try fwd --help)") }
        let cmd = commands.contains(first) ? first : "forward"
        let rest = commands.contains(first) ? Array(words.dropFirst()) : words
        return .request(ControlRequest(cmd: cmd, args: rest, keep: keep, wait: wait, off: off, all: all,
                                       timeout: timeout), json: json)
    }

    public static let help = """
        fwd: SSH port forwarding for the macOS menu bar

        Usage:
          fwd                              open the fwd window
          fwd [host] <port>...             forward ports and print their local URLs
          fwd forward [host] <port>...     the same, spelled out
          fwd status [host] [--all]        hosts and ports with their live state
          fwd wait [host] <port>           wait until a server answers on the port
          fwd off [host] <port>...         turn ports off (they stay in the list)
          fwd remove [host] <port>...      remove ports from the list
          fwd keep [host] <port>... [--off]  keep the host connected for these ports
          fwd connect [host]               connect a host now
          fwd screen [host]                open the host's screen in Screen Sharing
          fwd --version                    print the version

        Options:
          --json          print one JSON object, errors included
          --keep          (forward) also keep the host connected
          --wait          (forward) also wait until a server answers
          --timeout S     seconds to wait (forward 30, connect 30, wait 60)

        The host can be left out when exactly one host is connected.
        Ports: 3000   3000->4000   31** (3100-3199)   "5173 web" (with a name)

        Exit codes:
          0 done
          1 couldn't do it (the reason is printed)
          2 bad usage
          3 the fwd app couldn't be reached
          4 timed out

        Ports and settings: ~/.config/fwd/   Log: ~/Library/Logs/fwd/fwd.log
        """
}
```

```swift
// Sources/FwdCore/Control/ControlTarget.swift
import Foundation

/// The host and ports a command acts on, worked out from its arguments.
public struct ControlTarget: Equatable {
    public let host: String
    /// Port texts as they'd be typed in the panel, with any name:
    /// `3000`, `5173 web`, `3000 -> 4000`.
    public let ports: [String]

    public init(host: String, ports: [String]) {
        self.host = host
        self.ports = ports
    }

    /// Reads `[host] <port> [name] <port> [name]...`. The host is the first
    /// argument when it's a known host; otherwise it's left out and taken
    /// from `defaultHosts` when there's exactly one.
    public static func resolve(_ args: [String], hosts: [String], defaultHosts: [String],
                               noun: String) throws -> ControlTarget {
        var rest = args[...]
        let host: String
        if let first = rest.first, hosts.contains(first) {
            host = first
            rest = rest.dropFirst()
        } else if let first = rest.first, canonical(first) == nil {
            throw ControlError.usage("\"\(first)\" isn't a command, a host or a port (try fwd --help)")
        } else if defaultHosts.count == 1 {
            host = defaultHosts[0]
        } else if defaultHosts.isEmpty {
            throw ControlError.usage("no host is \(noun); say which, like: fwd devbox 3000")
        } else {
            throw ControlError.usage(
                "\(defaultHosts.count) hosts are \(noun) (\(defaultHosts.joined(separator: ", "))); say which, like: fwd \(defaultHosts[0]) 3000")
        }

        var ports: [String] = []
        var named = true  // the last port already has a name, so a word can't be one
        for arg in rest {
            if canonical(arg) != nil {
                ports.append(arg)
                named = EntryName.split(arg).name != nil
            } else if !named, let letter = arg.first, letter.isLetter, !arg.contains(" ") {
                ports[ports.count - 1] += " \(arg)"
                named = true
            } else {
                throw ControlError.usage("\"\(arg)\" isn't a port or a name for one (try fwd --help)")
            }
        }
        return ControlTarget(host: host, ports: ports)
    }

    /// The entry a port argument stands for, as ports.yaml stores it.
    public static func canonical(_ port: String) -> String? {
        try? PortPattern.parse(EntryName.split(port).port).text
    }
}
```

```swift
// Sources/FwdCore/Control/ControlHandler.swift
import Foundation

/// Runs command-line requests against the app, through the same actions the
/// panel uses, and answers with the hosts and ports as the panel shows them.
@MainActor
public final class ControlHandler {
    private let model: AppModel
    private let open: (URL) -> Void
    private let pollInterval: Double

    public init(model: AppModel, open: @escaping (URL) -> Void, pollInterval: Double = 0.2) {
        self.model = model
        self.open = open
        self.pollInterval = pollInterval
    }

    public func handle(_ request: ControlRequest) async -> ControlReply {
        guard request.v == ControlRequest.version else { return .failure(.versionMismatch) }
        model.log.write("cli: \(([request.cmd] + request.args).joined(separator: " "))")
        do {
            switch request.cmd {
            case "status": return status(request)
            case "forward": return try await forward(request)
            case "wait": return try await wait(request)
            case "off": return try await off(request)
            case "remove": return try await remove(request)
            case "keep": return try await keep(request)
            case "connect": return try await connect(request)
            case "screen": return try await screen(request)
            default: throw ControlError.usage("unknown command \(request.cmd) (try fwd --help)")
            }
        } catch let error as ControlError {
            return .failure(error)
        } catch let error as PortPattern.ParseError {
            return .failure(.usage("\(error)"))
        } catch {
            return .failure(.failed("\(error)"))
        }
    }

    // MARK: Reading the cards

    private var cards: [HostCard] { model.cards }
    private func card(_ host: String) -> HostCard? { cards.first { $0.name == host } }
    private var connected: [String] { cards.filter { $0.state == .connected }.map(\.name) }

    private func target(_ request: ControlRequest, needsPorts: Bool) throws -> ControlTarget {
        let target = try ControlTarget.resolve(request.args, hosts: cards.map(\.name),
                                               defaultHosts: connected, noun: "connected")
        if needsPorts, target.ports.isEmpty {
            throw ControlError.usage("say which port, like: fwd \(target.host) 3000")
        }
        return target
    }

    private func info(_ host: String, ports: [String]? = nil) -> HostInfo? {
        guard let card = card(host) else { return nil }
        return HostInfo(card: card, only: ports.map { Set($0.compactMap(ControlTarget.canonical)) })
    }

    /// Lets queued card rebuilds run, then checks `done` every poll until it
    /// gives an answer or the time runs out.
    private func until(_ timeout: Double, what: String,
                       _ done: () -> ControlReply?) async throws -> ControlReply {
        let deadline = Date().addingTimeInterval(timeout)
        while true {
            try await Task.sleep(nanoseconds: UInt64(pollInterval * 1_000_000_000))
            if let reply = done() { return reply }
            if Date() >= deadline { throw ControlError.timedOut("timed out after \(Int(timeout))s waiting for \(what)") }
        }
    }

    /// Why a host can't get anywhere right now, if it can't.
    private func stuck(_ card: HostCard) -> ControlError? {
        switch card.state {
        case .needsAttention(let message):
            return .failed("\(card.name) needs you: \(message) Run: fwd connect \(card.name) after fixing it")
        case .standby:
            return .failed("couldn't connect to \(card.name)" + (card.lastError.map { ": \($0)" } ?? ""))
        default:
            return nil
        }
    }

    // MARK: Commands

    private func status(_ request: ControlRequest) -> ControlReply {
        let host = request.args.first
        let shown = cards.filter { card in
            if let host { return card.name == host }
            return request.all || !card.pills.isEmpty || card.state == .connected
        }
        if let host, shown.isEmpty { return .failure(.usage("\"\(host)\" isn't a host fwd knows")) }
        return .success(hosts: shown.map { HostInfo(card: $0) })
    }

    private func forward(_ request: ControlRequest) async throws -> ControlReply {
        let target = try target(request, needsPorts: true)
        for port in target.ports {
            try await model.add(host: target.host, text: port)
            if request.keep, let text = ControlTarget.canonical(port) {
                try await model.setKeep(host: target.host, text: text, keep: true)
            }
        }
        let wanted = Set(target.ports.compactMap(ControlTarget.canonical))
        let what = request.wait ? "a server on \(target.host)" : "\(target.host) to forward"
        return try await until(request.timeout ?? 30, what: what) {
            guard let card = card(target.host) else { return nil }
            let host = HostInfo(card: card, only: wanted)
            if let error = stuck(card) { return .failure(error, host: host) }
            if let blocked = host.ports.first(where: { $0.state == "blocked" }) {
                return .failure(.failed("\(blocked.port) is blocked: \(blocked.reason ?? "")"), host: host)
            }
            guard card.state == .connected else { return nil }
            let done = host.ports.allSatisfy { port in
                if request.wait { return port.isLive }
                return port.forwards.isEmpty && port.port.contains("*") ? true : port.isForwarded
            }
            return done ? .success(host: host) : nil
        }
    }

    private func wait(_ request: ControlRequest) async throws -> ControlReply {
        let target = try target(request, needsPorts: true)
        guard target.ports.count == 1, let text = ControlTarget.canonical(target.ports[0]) else {
            throw ControlError.usage("wait takes one port, like: fwd wait \(target.host) 3000")
        }
        guard card(target.host)?.pills.first(where: { $0.text == text })?.on == true else {
            throw ControlError.failed("\(text) isn't on for \(target.host); run: fwd \(target.host) \(text)")
        }
        return try await until(request.timeout ?? 60, what: "a server on \(target.host) \(text)") {
            guard let card = card(target.host) else { return nil }
            let host = HostInfo(card: card, only: [text])
            if case .needsAttention = card.state, let error = stuck(card) { return .failure(error, host: host) }
            return host.ports.first?.isLive == true ? .success(host: host) : nil
        }
    }

    private func off(_ request: ControlRequest) async throws -> ControlReply {
        let target = try target(request, needsPorts: true)
        for port in target.ports {
            guard let text = ControlTarget.canonical(port) else { continue }
            if card(target.host)?.pills.first(where: { $0.text == text })?.on == true {
                try await model.toggle(host: target.host, text: text)
            }
        }
        return .success(host: info(target.host, ports: target.ports)
            ?? HostInfo(card: HostCard(name: target.host, state: .idle, statusLine: "", pills: [],
                                       configPills: [], lastError: nil, inConfig: false)))
    }

    private func remove(_ request: ControlRequest) async throws -> ControlReply {
        let target = try target(request, needsPorts: true)
        for port in target.ports {
            if let text = ControlTarget.canonical(port) { try await model.remove(host: target.host, text: text) }
        }
        return .success(host: info(target.host, ports: target.ports)
            ?? HostInfo(card: HostCard(name: target.host, state: .idle, statusLine: "", pills: [],
                                       configPills: [], lastError: nil, inConfig: false)))
    }

    private func keep(_ request: ControlRequest) async throws -> ControlReply {
        let target = try target(request, needsPorts: true)
        for port in target.ports {
            if let text = ControlTarget.canonical(port) {
                try await model.setKeep(host: target.host, text: text, keep: !request.off)
            }
        }
        return .success(host: info(target.host, ports: target.ports)!)
    }

    private func connect(_ request: ControlRequest) async throws -> ControlReply {
        // Here the host left out is the one host waiting to connect.
        let waiting = cards.filter { $0.state != .connected && $0.pills.contains(where: \.on) }.map(\.name)
        let target = try ControlTarget.resolve(request.args, hosts: cards.map(\.name),
                                               defaultHosts: waiting, noun: "waiting to connect")
        guard card(target.host)?.pills.contains(where: \.on) == true else {
            throw ControlError.failed("\(target.host) has no ports on; forward one first, like: fwd \(target.host) 3000")
        }
        await model.connect(host: target.host)
        return try await until(request.timeout ?? 30, what: "\(target.host) to connect") {
            guard let card = card(target.host) else { return nil }
            if let error = stuck(card) { return .failure(error, host: HostInfo(card: card)) }
            return card.state == .connected ? .success(host: HostInfo(card: card)) : nil
        }
    }

    private func screen(_ request: ControlRequest) async throws -> ControlReply {
        let target = try target(request, needsPorts: false)
        let url = try await model.screenSharingURL(host: target.host)
        open(url)
        return .success(host: info(target.host)!, url: url.absoluteString)
    }
}
```

```swift
// Sources/FwdCore/Control/UnixSocket.swift
import Darwin
import Foundation

/// The few socket calls the control server and client share.
enum UnixSocket {
    static func address(_ path: String) throws -> sockaddr_un {
        var addr = sockaddr_un()
        addr.sun_family = sa_family_t(AF_UNIX)
        let bytes = Array(path.utf8)
        guard bytes.count < MemoryLayout.size(ofValue: addr.sun_path) else {
            throw ControlError.failed("socket path is too long: \(path)")
        }
        withUnsafeMutableBytes(of: &addr.sun_path) { raw in
            raw.copyBytes(from: bytes)
            raw[bytes.count] = 0
        }
        return addr
    }

    /// Reads up to a newline. Returns nil on end of file, a timeout or an
    /// error; throws if the line runs past `max` bytes.
    static func readLine(_ fd: Int32, max: Int) throws -> Data? {
        var line = Data()
        var chunk = [UInt8](repeating: 0, count: 4096)
        while true {
            let n = read(fd, &chunk, chunk.count)
            if n <= 0 { return nil }
            if let newline = chunk[0..<n].firstIndex(of: UInt8(ascii: "\n")) {
                line.append(contentsOf: chunk[0..<newline])
                return line
            }
            line.append(contentsOf: chunk[0..<n])
            if line.count > max { throw ControlError.usage("the request is too long") }
        }
    }

    static func writeAll(_ fd: Int32, _ data: Data) throws {
        try data.withUnsafeBytes { raw in
            var sent = 0
            while sent < raw.count {
                let n = write(fd, raw.baseAddress! + sent, raw.count - sent)
                guard n > 0 else { throw ControlError(.unreachable, "the connection closed") }
                sent += n
            }
        }
    }

    static func setTimeout(_ fd: Int32, _ seconds: TimeInterval) {
        var tv = timeval(tv_sec: Int(seconds), tv_usec: Int32((seconds - floor(seconds)) * 1_000_000))
        setsockopt(fd, SOL_SOCKET, SO_RCVTIMEO, &tv, socklen_t(MemoryLayout<timeval>.size))
        setsockopt(fd, SOL_SOCKET, SO_SNDTIMEO, &tv, socklen_t(MemoryLayout<timeval>.size))
        var on: Int32 = 1
        setsockopt(fd, SOL_SOCKET, SO_NOSIGPIPE, &on, socklen_t(MemoryLayout<Int32>.size))
    }
}
```

```swift
// Sources/FwdCore/Control/ControlServer.swift
import Darwin
import Foundation

/// Answers the `fwd` command line on a Unix socket: one JSON request line in,
/// one reply line out, per connection. The socket lives in fwd's private
/// socket folder, and only the same user may talk to it.
public final class ControlServer: @unchecked Sendable {
    public let path: String
    private let handle: @MainActor (ControlRequest) async -> ControlReply
    private var listener: Int32 = -1
    private var source: DispatchSourceRead?
    /// Reading a request can take a slow client up to 5 seconds, so each one
    /// is read off the listening queue.
    private let readers = DispatchQueue(label: "fwd.control.read", attributes: .concurrent)

    static let maxRequest = 64 * 1024
    static let readTimeout: TimeInterval = 5

    public init(path: String, handle: @escaping @MainActor (ControlRequest) async -> ControlReply) {
        self.path = path
        self.handle = handle
    }

    public func start() throws {
        // A socket file left by a crashed run would make bind fail.
        unlink(path)
        let fd = socket(AF_UNIX, SOCK_STREAM, 0)
        guard fd >= 0 else { throw ControlError.failed("couldn't make the control socket") }
        var addr = try UnixSocket.address(path)
        let bound = withUnsafePointer(to: &addr) {
            $0.withMemoryRebound(to: sockaddr.self, capacity: 1) { bind(fd, $0, socklen_t(MemoryLayout<sockaddr_un>.size)) }
        }
        guard bound == 0, chmod(path, 0o600) == 0, listen(fd, 16) == 0 else {
            close(fd)
            throw ControlError.failed("couldn't listen on \(path): \(String(cString: strerror(errno)))")
        }
        listener = fd
        let source = DispatchSource.makeReadSource(fileDescriptor: fd, queue: DispatchQueue(label: "fwd.control"))
        source.setEventHandler { [weak self] in self?.acceptOne() }
        source.setCancelHandler { close(fd) }
        source.resume()
        self.source = source
    }

    public func stop() {
        source?.cancel()
        source = nil
        unlink(path)
    }

    private func acceptOne() {
        let client = accept(listener, nil, nil)
        guard client >= 0 else { return }
        var uid: uid_t = 0
        var gid: gid_t = 0
        guard getpeereid(client, &uid, &gid) == 0, uid == getuid() else {
            close(client)
            return
        }
        UnixSocket.setTimeout(client, Self.readTimeout)
        readers.async { [handle] in
            let request: Result<ControlRequest, ControlError>
            do {
                guard let line = try UnixSocket.readLine(client, max: Self.maxRequest) else {
                    close(client)
                    return
                }
                request = .success(try ControlRequest.decode(line))
            } catch let error as ControlError {
                request = .failure(error)
            } catch {
                request = .failure(.usage("couldn't read the request: \(error.localizedDescription)"))
            }
            Task { @MainActor in
                let reply: ControlReply
                switch request {
                case .success(let r): reply = await handle(r)
                case .failure(let e): reply = .failure(e)
                }
                // Waiting commands can take minutes; the reply write gets
                // its own generous timeout.
                UnixSocket.setTimeout(client, 10)
                try? UnixSocket.writeAll(client, reply.encodedLine())
                close(client)
            }
        }
    }
}
```

```swift
import Darwin
import Foundation

/// The `fwd` command's side of the control socket.
public enum ControlClient {
    /// Nothing answered on the socket: the app isn't running (or is starting).
    public struct Unreachable: Error {}

    public static func send(_ request: ControlRequest, to path: String, timeout: TimeInterval) throws -> ControlReply {
        let fd = socket(AF_UNIX, SOCK_STREAM, 0)
        guard fd >= 0 else { throw Unreachable() }
        defer { close(fd) }
        var addr = try UnixSocket.address(path)
        let connected = withUnsafePointer(to: &addr) {
            $0.withMemoryRebound(to: sockaddr.self, capacity: 1) {
                Darwin.connect(fd, $0, socklen_t(MemoryLayout<sockaddr_un>.size))
            }
        }
        guard connected == 0 else { throw Unreachable() }
        UnixSocket.setTimeout(fd, timeout)
        try UnixSocket.writeAll(fd, request.encodedLine())
        guard let line = try UnixSocket.readLine(fd, max: 16 << 20) else {
            throw ControlError.timedOut("the fwd app didn't answer in time")
        }
        return try ControlReply.decode(line)
    }
}
```

```swift
// Sources/FwdCore/Control/ControlFormat.swift
import Foundation

/// How the `fwd` command prints replies.
public enum ControlFormat {
    public static func json(_ reply: ControlReply) -> String {
        String(decoding: reply.encodedLine().dropLast(), as: UTF8.self)
    }

    public static func human(_ reply: ControlReply, command: String) -> String {
        guard reply.ok else { return "fwd: \(reply.error ?? "something went wrong")" }
        if let url = reply.url { return url }
        if let hosts = reply.hosts {
            if hosts.isEmpty { return "No hosts with ports. Forward one with: fwd <host> <port>" }
            return hosts.map { host in
                (["\(host.host)  \(host.status.isEmpty ? host.state : host.status)"]
                    + table(host.ports.map { row($0) }).map { "  " + $0 }).joined(separator: "\n")
            }.joined(separator: "\n")
        }
        guard let host = reply.host else { return "" }
        return table(host.ports.map { [host.host] + row($0) }).joined(separator: "\n")
    }

    /// A port's columns: label, URL, state, and a note.
    private static func row(_ port: PortInfo) -> [String] {
        let label = port.name.map { "\($0) \(port.port)" } ?? port.port
        var note = port.reason ?? ""
        if port.state == "waiting" { note = "nothing listening on the remote yet" }
        if port.state == "pending" { note = "waiting for the host" }
        if port.keep { note = note.isEmpty ? "kept" : "\(note), kept" }
        var rows = [label, port.url ?? "", port.state, note]
        if !port.forwards.isEmpty {
            rows[3] = port.forwards.map { "\($0.remote)→\($0.local.map(String.init) ?? "?")" }.joined(separator: " ")
        }
        return rows
    }

    /// Pads columns to line up, dropping trailing spaces.
    private static func table(_ rows: [[String]]) -> [String] {
        guard let width = rows.map(\.count).max() else { return [] }
        let widths = (0..<width).map { col in rows.map { col < $0.count ? $0[col].count : 0 }.max() ?? 0 }
        return rows.map { row in
            row.enumerated().map { col, cell in
                col == row.count - 1 ? cell : cell.padding(toLength: widths[col], withPad: " ", startingAt: 0)
            }.joined(separator: "  ").replacingOccurrences(of: "\\s+$", with: "", options: .regularExpression)
        }
    }
}
```

```swift
// Sources/FwdCore/Control/CLIRunner.swift
import Foundation

/// The command's request loop: ask the app, and if it isn't running, start
/// it once and keep asking while it comes up.
public enum CLIRunner {
    public static func send(_ request: ControlRequest, socket: String, launch: () -> Void,
                            attempts: Int = 50, delay: TimeInterval = 0.2) -> ControlReply {
        // Long enough for the slowest command, plus room to answer.
        let timeout = (request.timeout ?? 60) + 10
        var launched = false
        for _ in 0..<max(attempts, 1) {
            do {
                return try ControlClient.send(request, to: socket, timeout: timeout)
            } catch is ControlClient.Unreachable {
                if !launched {
                    launch()
                    launched = true
                }
                Thread.sleep(forTimeInterval: delay)
            } catch let error as ControlError {
                return .failure(error)
            } catch {
                return .failure(ControlError(.unreachable, "the fwd app gave an answer this command can't read; update fwd"))
            }
        }
        return .failure(ControlError(.unreachable, "couldn't reach the fwd app; is it installed? (open -a fwd)"))
    }
}
```

```swift
    guard let app, let data = try? Data(contentsOf: app.appendingPathComponent("Contents/Info.plist")),
          let info = try? PropertyListSerialization.propertyList(from: data, format: nil) as? [String: Any],
          let version = info["CFBundleShortVersionString"] as? String else { return "dev" }
    return version

/// Opens fwd by bundle identifier, so a copy that's already running answers
/// even if it was started from another path; falls back to this copy.
func openApp(window: Bool) {
    func run(_ args: [String]) -> Bool {
        let p = Process()
        p.executableURL = URL(fileURLWithPath: "/usr/bin/open")
        p.arguments = args
        p.standardOutput = FileHandle.nullDevice
        p.standardError = FileHandle.nullDevice
        guard (try? p.run()) != nil else { return false }
        p.waitUntilExit()
        return p.terminationStatus == 0
    }
    let extra = window ? ["--args", "--show-window"] : []
    let quiet = window ? [] : ["-g"]
    if run(quiet + ["-b", Paths.bundleIdentifier] + extra) { return }
    if let app { _ = run(quiet + [app.path] + extra) }
}

func fail(_ message: String, _ code: ExitCode) -> Never {

    exit(Int32(code.rawValue))
```

````markdown
### From the terminal

The `fwd` command does what the panel does, so you, scripts and coding
agents can forward ports without clicking:

```sh
fwd devbox 3000           # forward devbox:3000, print http://localhost:3000
fwd 3000                  # the same, when devbox is the one connected host
fwd 3000 5173 web --keep  # several ports, with a name, kept connected
fwd wait 3000             # block until a server answers on devbox:3000
fwd status                # hosts and ports with their live state
fwd off 3000              # turn it off;  fwd remove 3000 forgets it
fwd                       # open the window
```

is in `error`), 2 bad usage, 3 the fwd app isn't reachable, 4 timed out.
`fwd 3000 --wait --json` forwards and returns once a server answers.
`fwd --help` lists everything.

The command starts fwd if it isn't running. Homebrew installs it; otherwise
````
